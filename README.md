# 机械设计基础 · 刷题与全真模考

一个**单文件、零依赖、纯离线**的复习网页：87 道题、21 张图全部内嵌，双击即用，学习进度存在本机浏览器。

> 在线访问：**https://ziren371-art.github.io/mech-design-review/**

## 功能

- **87 道题专项刷题** —— 填空 30 / 选择 26 / 简答 11 / 分析 6 / 计算 14，可按章节与题型筛选。
- **背题模式** —— 直接看答案与解析，适合考前快速过一遍。
- **100 分全真模考** —— 填空 10×2 + 选择 7×2 + 简答 4×5 + 分析 2×8 + 计算 4 题（自由度 7 / 齿轮 7 / 轮系 8 / 轴承 8），共 27 题，交卷自动批改。
- **自动错题本** —— 答错的题自动归档，支持反复重做。
- **进度统计** —— 各题型正确率与完成度。
- **插图与灯箱** —— 21 张原题图（含答案叠加图）内嵌在页面中，点图全屏放大。

## 判分约定

- 填空题按空分槽判分，忽略空格、`°` 与数值单位（mm / N / 度 / r/min 等），并支持同义写法（如「动力系统 / 动力装置」「仿形法 / 成形法」「联接 / 连接」）。
- 选择题第 14 题与第 24 题内容重复，均标「重题」；模拟考池排除第 24 题，只在 25 道有效题中抽 7 题。
- 填空题第 6 题按「背记卡」展示、不参与抽题，其余 29 道填空参与抽 10 题。
- 公式全部用 `<sub>` / `<sup>` + Unicode 排版，不加载 MathJax / KaTeX 等任何外部脚本。

## 部署方式

站点只有 `index.html`（825 KB，含全部 CSS / JS / 21 张 Base64 图）和一个空的 `.nojekyll`。没有构建步骤、没有 npm 依赖、**不请求任何外部域名**，断网也能完整使用。

托管在 GitHub Pages：`main` 分支根目录，构建方式 `Deploy from a branch`。

> 源文件名原为 `机械设计基础复习资料_刷题与模拟考.html`，为让站点根路径可直接访问，发布时重命名为 `index.html`，内容未做任何改动。

## 本地使用

直接双击 `index.html` 即可在浏览器打开（`file://` 协议下功能完整，但无法分享给别人）。

手机端建议在浏览器里「添加到主屏幕」，可全屏运行、无地址栏。

## 数据与隐私

页面不发任何网络请求；学习进度、错题记录、模考成绩只写入本机 `localStorage`，不上传、不同步。清缓存或换设备会丢失记录。
